## 要验什么

「按住时连续执行」是按键级的 **radio 四选一**（双击不参与），显示在单击、长按两个
编辑页底部，两页是同一个状态：

- **自动**（默认）：没有长按动作且单击可重复时连续单击，有长按动作时执行长按一次。
- **关闭**：按住只执行一次，单独保存明确关闭。
- **重复单击动作**：单击立即执行后连续（无双击时 0.35 秒起拍；有双击时按住超过
  0.3 秒即确认为单击并执行首次动作，0.35 秒起连续，快速点按仍判双击）。
- **重复长按动作**：长按动作 0.55 秒执行一次后，按该键间隔继续续拍。
- 控件只出现在**返回 / 方向 / 音量+ / 音量−**；只对**可连续执行**的动作可选
  （单键、滚动、鼠标移动；组合快捷键、打开应用、聚焦输入框、鼠标点击只执行一次）。
- 单击与长按并存时「重复单击动作」不可选；仅当长按动作可重复时指向「重复长按动作」，否则提示先清除长按动作；
  已选目标因配置变化不再可用时自动回到「关闭」并提示（不偷改选择）。

历史自动化已覆盖显式连发状态机与三态界面；新默认自动和四态界面的结果以上述当前候选记录为准，不将旧迁移测试重复当作本轮操作。本手册的实体用例验证真机与第三方应用可见效果。

## 用例

**E0 · 默认自动（本次新增）**
配置：返回单击 Backspace、四方向对应单键，长按未配置，连发选自动（缺省）。
判据：短按只执行一次，按住约 0.35 秒开始连续单击，松开立即停止；增加长按动作后只执行该长按一次，清除后恢复自动单击。明确选关闭再保存/重开仍关闭，重新选自动才恢复默认行为。此用例分别验证模板编辑与实际应用，编辑草稿不得偷偷切换当前模板。

**E1 · 重复单击动作（无双击）**
配置：返回键（或方向键）单击=「Delete」，不配置双击/长按，组里选「重复单击动作」。
步骤与判据：点按一次 → 删除 1 个字符；按住 ≥1 秒 → 约 0.35 秒起连续删除；松开立即停、无粘键。
日志：`map_repeat start … trigger=single interval_ms=50` → `map_repeat end … reason=release beats=N`。

**E2 · 重复长按动作**
配置：返回键 单击=「Delete」、长按=「Backspace」，组里选「重复长按动作」。
判据：点按 → 删除一次；按住 → 约 0.55 秒退格 1 次，随后按约 50ms 间隔连续退格；松开即停。
日志：`map_repeat start … trigger=long` 与逐拍 `map_fire … trigger=long`。

**E3 · 双击共存（重复单击动作 + 双击）**
配置：返回键 单击=「Delete」、双击=「Space」，组里选「重复单击动作」。
判据：快速双击 → 空格；单次点按 → 约 0.3 秒后删除；按住 → 约 0.3 秒时删除一次，0.35 秒起连续；
该次按住松开后立刻再点按，不得误判为双击（按新序列的单击处理）。

**E4 · 不可连续执行的动作**
- 单击=「Ctrl+C」：进单击页 → 「重复单击动作」置灰，原因写“‘单击’的动作只执行一次…改成单个按键后可选”；按住只复制一次。
- 长按=「打开应用」（或组合键）：进长按页 → 「重复长按动作」置灰，原因写“‘长按’的动作只执行一次…把它改成单个按键后可选”；按住只打开一次应用。
- 同一按键进单击页 → 原因写“要连续执行单击动作，请先清除长按动作”，**不得出现“请选‘重复长按动作’”**（它是灰的）；两页说明句均不含“开启‘按住时连续执行’后…”的承诺。

**E5 · 键范围负例**
确定键 / 主页键等：编辑区不显示该选项组；按住不产生连续执行（配置了长按也只执行一次）。

**E6 · 并存与变更收口**
① 长按=可连续动作（如 Backspace）时进单击页 → 「重复单击动作」置灰，原因写“…请选‘重复长按动作’”，可直接改选「重复长按动作」；
② 选好「重复单击动作」后再为该键配置长按：长按**可连续** → 自动回到「关闭」并提示（指向「重复长按动作」，随即可改选）；长按**不可连续**（打开应用等）→ 提示写“…按住会执行长按，而它只执行一次，‘按住时连续执行’已关闭”，**不得出现“请选‘重复长按动作’”**。

**E7 · 回归**
双击判定、锁定动作（Win+L 等释放后执行）、语音键生命周期（按下开始/松开结束、
不参与双击/长按延迟）、快速连按均与升级前一致。

**E8 · 边界**
按住期间断开遥控器 / 系统睡眠 / 退出应用 → 无粘键、无迟到连续拍；
闲置后首次按压（冷态）仍能正常起拍与连续。日志应出现
`map_repeat end … reason=reset|reconfigure|shutdown` 且之后无该键的 `map_repeat`/`map_fire`。

**E9 · 当前配置读回与导入导出**
结构版本 2：缺省 `holdRepeat` 读为「自动」，明确选择关闭保存为 `off`，保存/重开及导出/导入后仍关闭；明确 `single` / `long` 保留原选择，重新选自动时省略该字段。旧缺字段按新规则解释为自动，不猜测其历史选择，不批量改模板或重跑旧迁移。高于当前支持版本的配置必须拒绝降级与覆盖；取消或校验失败不得替换实际运行映射。模板编辑与实际应用继续分离。10 月 6 日曾执行的旧版迁移目视只作历史证据，不作为本轮步骤。

## 失败处置

| 现象 | 先看什么 |
| --- | --- |
| 按住完全不连续 | 该键是否有事件（返回/音量键需先开启「全按键支持」）；日志有无 `map_fire`/`map_inject` 逐拍记录；选择为自动时核对七键范围、单击可重复且没有长按动作，或核对显式重复单击/长按目标是否有效 |
| 明确关闭的按键也出现 `map_repeat` | 回归；缺省自动满足条件时应有连续拍。只有连续触发计时器产生的拍才计入聚合，双击窗补发的单击与首次长按是一次性手势 |
| 连续一拍后就停 | `release` 边沿是否提前到达（粘键/迟滞）；日志 `map_repeat end` 的 reason 与 beats |
| 按一下出两次 | 该键是否走了泄漏对冲路径且动作与原生相同；对照 `map_skip_inject` 记录 |
| 选项置灰 | 按键是否在范围内、动作是否可连续执行、该键是否已配长按动作（悬停与常驻原因即说明） |
| 升级后行为与旧版不一致 | 核对实际安装包与 `schemaVersion` / `holdRepeat`；本次缺字段改为自动，明确关闭应为 `off`，旧缺字段不代表可恢复的明确关闭；组合键仍不连续 |

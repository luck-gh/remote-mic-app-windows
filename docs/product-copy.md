# 产品文案规范（用户可见文案）

本文件随 2026-10-02 Windows 上游同步吸收通用文案约定；适用于界面与[用户手册](installation-and-configuration.md)的用户可见章节。产品范围、权限与真实能力边界以 [AGENTS.md](../AGENTS.md)、[PLAN.md](PLAN.md) 和 [FEATURES.md](FEATURES.md) 为准。

本地保留指定按键的独立 Helper 增强，不采用上游“全按键支持”、最高权限计划任务或语音报告合成，不能承诺“只授权一次”或把输入工具选择写成增强开关。上游原文和决策可在 [固定提交](https://github.com/GetSayAll/remote-mic-app-windows/blob/c81308e011a757dc22d22f2861b687ef787d295e/docs/product-copy.md) 追溯，不视为本地用户新增授权。

## 1. 适用范围

- **适用**：页面与卡片标题、说明句、按钮、开关与标签、状态句、悬停提示、空状态、
  错误与重试提示、确认弹窗、安装器与更新流程里用户可见的文字、用户手册的面向用户章节。
- **不适用**：代码标识符与注释、`Testing/`、`Bugs/`、`docs/investigations/`、诊断日志，
  以及用户手册 §10「AI Agent 执行协议」（面向自动化与技术支持）。

## 3. 面向用户解释结果与必要条件

普通状态句优先说明用户可观察的结果，避免堆砌报告层、HID、Raw Input、会话代次等实现术语。权限、可选增强、正常清理和失败原因涉及用户决策时必须如实说明；不能为去术语化隐藏管理员授权、以运行中代替就绪，或修改现行驱动页和模板契约。

**用户必须知情的内容照写，但说结果、不说机制**：

- 限定增强启动可能触发 Windows 管理员授权；取消不自动重试，正常清理确认前不并起第二个 Helper，不承诺一次授权永久免提示；
- VB-CABLE 安装需要管理员权限，是否重启按其安装结果和现有指南说明；
- 可选增强的兼容性与安全软件边界按已验证事实说明，不把上游全按键路线风险当成本地行为；
- 隐私按真实数据流说明：设备来源限定，不记录设备身份、个人路径或语音内容；不要作“应用完全不收集任何信息”的扩大承诺；
- 微信输入法语音识别需要联网、要求按住约半秒；遥控器按键默认行为；
- 服务方与技术名（蓝牙、遥控器、语音键、输入法、快捷键、Windows、VB-CABLE）。

## 4. 写法约定

- **一句一个意思**；状态句陈述现状，动作句以动词开头。
- 称呼用户用「你」，不用「本应用 / 该功能 / 用户」。
- **数字与拉丁词两侧加空格**：`左 Ctrl + 左 Win`、`小米蓝牙语音遥控器 2`、`约 0.5 秒`。
- 引用界面上的名称用中文双引号 “”（如“重新启动增强”“设置”“是”）；
  「」只留给注释与文档。
- 按钮是动词短语（2–6 字）：扫描已配对设备 / 断开 / 更换设备 / 打开官方下载页。
- 未知与空状态给下一步，不给结论式抱怨：型号未读回先显示蓝牙名并等它读回。
- 错误提示说清「发生了什么 ＋ 你该怎么办」；不贴内部错误原文（必要的错误码进诊断摘要）。
- 同一设置出现在两处时，两处含义和保存结果保持一致，例如按键页与模板页的菜单键模板开关。
- 卡片说明一句话（≤ 40 字）；更长的解释放进「常见问题」折叠，不铺在首屏。

## 5. 落点与单一来源

- 前端用户可见字符串集中于 `src/pages/*.vue`、`src/components/*.vue`、`src/lib/*.ts` 的 label 函数和 `src/navigation.ts`；宿主原生失败提示与安装器保留各自职责，手册同步实际行为。
- 同一概念只定义一次，其他地方引用（型号、按键名、阶段文案都走 label 函数）。
- 新增或修改用户可见功能时同步用户手册对应章节，并按 [AGENTS.md](../AGENTS.md) 检查 `TODO.md`。

1. 名称表里的对象是否用了表里的写法（尤其型号走 `remoteModelLabel`）？
2. 扫描实现术语后逐处判断是否为用户决策所必需，不机械删除：

   ```powershell
   rg -n "注入|模拟|钩子|报告层|HID|宿主|提权|计划任务|Raw Input|ATVV|GATT|BLE|内核|驱动|端口|边沿|白名单|令牌" src/pages src/components src/lib docs/installation-and-configuration.md
   ```

3. 是否残留旧名称（例如缺「语音」的“小米蓝牙遥控器 2”）？
4. 引号、空格是否符合第 4 节？
5. 用户手册是否同步？
6. 权限、失败反馈和配置保存等行为是否有相应验证？文案调整不单独要求镜像字符串测试。

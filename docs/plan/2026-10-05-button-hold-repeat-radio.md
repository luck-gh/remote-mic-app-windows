# 「按住时连续执行」交互规则

## 2026-10-12 当前规则：未配置长按时默认连续单击

用户明确要求返回与方向键在没有长按动作时，按住连续执行单击。当前规则取代下方 10 月 5 日历史方案中的缺省关闭和三选一；其余动作白名单、时间参数、按键范围及成对停止契约保持。

| 选项 | 按住行为 |
| --- | --- |
| 自动（默认） | 没有长按动作且单击动作可重复时，连续单击；已有长按动作时执行长按一次 |
| 关闭 | 只执行该次单击或长按，不连发 |
| 重复单击动作 | 无长按动作且单击动作可重复时可选 |
| 重复长按动作 | 长按动作可重复时可选，长按触发后续拍 |

范围仍为返回、四方向、音量加减；单个非修饰键、滚动、鼠标移动可重复，组合快捷键、打开应用、鼠标点击等只执行一次。菜单、语音和其他按键不增加默认连发。自动模式的当前行为在编辑器中说明；添加或清除长按只改变自动模式的有效行为，不擅自改为显式重复长按。显式单击/长按连发因动作变化而失效时收口为明确关闭并提示。

`holdRepeat` 缺省表示自动，显式值为 `off|single|long`；结构版本为 2，复用现有版本校验、保存及导出。不新增转换或批量改配置。旧版把未设置和关闭都存为缺字段，历史意图不能恢复；按用户本次要求统一解释为自动，今后的关闭独立保存。场景/任务导航仅用于识别的占位动作明确关闭重复，不能因默认变化变成连续注入。

验证要求：先红后绿覆盖缺省自动、关闭、长按优先、动作/按键白名单、双击共存、松开/重配/断连/退出取消与有效状态日志；配置加载/保存/导出不物化自动选择。实际 RC003 长按方向与返回、短按、松开停止、实体键盘和菜单/语音回归分别记录，不能用旧包结果代替。任务与结果归 TODO 和 [原验收手册](../../Testing/WindowsButtonGestureRepeat.md)。

## 1. 背景与三轮演化

1. **初版（已实现，`afa8ff8`）**：每键一个开关「按住连续触发」，通过**它显示在
   哪一页**（单击/长按编辑页）来表达"连续执行哪个动作"。问题：状态隐式、
   文案出现"开在长按列""请把开关开在长按列""互斥"等配置模型行话，用户看不懂。
2. **简化提案（一个开关 + 自动跟随）**：被否——用户要保留"显式选择"。
3. **定稿（radio 三选一）**：一个控件、三个状态，目标选择显式可见：

```
按住时连续执行    [关闭]  [重复单击动作]  [重复长按动作]
```

- 位置：保持在**编辑面板页底**（单击/长按编辑页；双击编辑页不显示，双击不参与）。
- 单击页与长按页显示**同一个状态**（按键级，不是槽位级）。
- 三个选项用现有 chip 样式（与"安全录入模式"的修饰键一致）：选中高亮；
  不可选置灰 + 悬停"原因 + 恢复方式"；当前页面对应的选项若不可选，
  原因另常驻在组下方一行（沿用原 `.repeat-hint` 位置）。

## 2. 语义（选中项 → 按住行为）

| 配置 | 按住行为（选中"重复单击动作"） | 按住行为（选中"重复长按动作"） |
| --- | --- | --- |
| 双击与长按均未配置 | 单击立即执行，随后按间隔连续 | 不适用（无长按动作） |
| 已配置双击 | 按住超约 0.3 秒按单击处理，随后连续 | 不适用（同上） |
| 已配置长按 | 不可选（按住会先执行长按） | 长按约 0.55 秒执行一次，随后按间隔连续 |

- 连发间隔沿用逐键口径（返回 50ms，方向/音量 100ms；`RemoteButton::repeat_interval`）。
- "关闭"= 按住只执行一次（默认）。

## 3. 选项可用性规则（置灰条件与原因）

| 选项 | 不可选条件 | 原因文案（悬停；当前页对应项另常驻一行） |
| --- | --- | --- |
| 重复单击动作 | 单击动作未配置 | 先给这个按键配置单击动作 |
| 重复单击动作 | 单击动作"只执行一次"（组合快捷键、打开应用等，非单个按键） | “单击”的动作只执行一次（组合快捷键、打开应用等），不能连续执行；改成单个按键后可选 |
| 重复单击动作 | 已配置长按动作，且长按动作**可连续执行** | 这个按键已有长按动作，按住会先执行长按；要连续执行，请选“重复长按动作” |
| 重复单击动作 | 已配置长按动作，且长按动作**只执行一次**（2026-10-05 用户反馈修订：不得指向灰掉的选项） | 这个按键已有长按动作：按住会执行长按。要连续执行单击动作，请先清除长按动作 |
| 重复长按动作 | 长按动作未配置 | 先给这个按键配置长按动作 |
| 重复长按动作 | 长按动作"只执行一次" | “长按”的动作只执行一次（组合快捷键、打开应用等），不能连续执行；把它改成单个按键后可选 |
| 关闭 | 恒可选 | — |

- 整个控件只在可连续按键（返回 / 方向 / 音量+−）的单击、长按编辑页显示。
- "改成单个按键后可选"的判据与引擎 `ButtonAction::allows_repeat` 同源（单个非修饰键、
  或滚动/移动类动作）。

## 4. 配置变更时的收口（不偷改用户选择）

| 变更 | 处理 |
| --- | --- |
| 已选"重复单击动作"，随后配置了**可连续执行**的长按动作 | 自动回到"关闭"并提示：**这个按键已配置长按动作：按住会先执行长按，“按住时连续执行”已关闭（要连续执行，请选“重复长按动作”）** |
| 已选"重复单击动作"，随后配置了**只执行一次**的长按动作 | 自动回到"关闭"并提示：**这个按键已配置长按动作：按住会执行长按，而它只执行一次，“按住时连续执行”已关闭** |
| 已选目标动作被改成"只执行一次" | 自动回到"关闭"并提示：**动作已变更，“按住时连续执行”已关闭** |
| 其他（目标仍可用） | 保持现状，不提示 |

原则：自动关闭的提示与常驻原因一样，**永不指向不可选的选项**；每条提示只讲一句事实 +（可用时）一条可行下一步。

## 5. 文案（唯一实现依据）

| 位置 | 文案 |
| --- | --- |
| 分组标签 | 按住时连续执行 |
| 选项 1 | 关闭 |
| 选项 2 | 重复单击动作 |
| 选项 3 | 重复长按动作 |
| 悬停·关闭 | 按住不放只执行一次 |
| 悬停·重复单击动作（未配双击） | 按住不放，单击动作会不断重复，直到松手 |
| 悬停·重复单击动作（已配双击） | 按住超过约 0.3 秒开始，单击动作会不断重复，直到松手 |
| 悬停·重复长按动作 | 按住约 0.55 秒后，长按动作会不断重复，直到松手 |
| 状态条·选关闭 | 已关闭“按住时连续执行” |
| 状态条·选重复单击动作 | 已开启：按住不放会连续执行 |
| 状态条·选重复长按动作 | 已开启：长按后不松手会继续连续执行 |
| 单击页说明句（未配双击） | 单击在按下瞬间执行。 |
| 单击页说明句（已配双击） | 配置了双击：单击会稍等片刻（约 0.3 秒）以区分双击。 |
| 长按页说明句 | 长按约 0.55 秒后执行。 |
| 双击页说明句 | 配置后单击会稍等片刻（约 0.3 秒）以区分双击。双击不会连续执行。 |

说明句与选项的关系（2026-10-05 用户反馈修订）：**说明句只陈述本页事实，不承诺“开启后
会连续执行”**（那是选项的行为，写在选项悬停里）；页面常驻原因只讲本页那个选项，
两个选项都不可选时也不出现互相矛盾的指路。单击页“已有长按动作”的原因句在指路前
先确认“重复长按动作”真的可选。

文案规范核对（`docs/product-copy.md` §4）：界面引用名称用中文双引号“”；数字与拉丁词
两侧空格（约 0.3 秒 / 约 0.55 秒）；不出现术语红线词；开关/选项文字在前、控件在后。

## 6. 明确不做

- **双击语义不动**：先点一下、紧接着第二下按住不放，在"关闭"状态下松手仍按双击处理
  （改装前既有的默认语义，2026-10-05 用户确认保持）。
- Rust 引擎、按键映射存储格式、schema 迁移不改（radio 只是初版 `holdRepeat` 的
  另一种呈现方式）。
- 不做"一个开关 + 自动跟随目标"方案（用户 2026-10-05 明确要显式选择）。
